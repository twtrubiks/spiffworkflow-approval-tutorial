圖形與 XML 標籤對照

細線圓圈<bpmn:startEvent> 開始事件。do_engine_steps() 一開始就自動通過
粗線圓圈<bpmn:endEvent> 結束事件。走到這裡 workflow.completed 會變成 True
方框＋人像<bpmn:userTask> 人工任務。流程會停在這裡，等程式呼叫 task.complete()
方框＋捲軸<bpmn:scriptTask> 腳本任務。do_engine_steps() 時自動執行裡面的 Python
菱形＋X<bpmn:exclusiveGateway> 互斥閘道。依連線上的條件只走其中一條
線頭有斜槓閘道的 default 連線。其他條件都不成立時走這條
箭頭線<bpmn:sequenceFlow> 連線。可以帶 <conditionExpression> 條件
XML 原始碼（灰色部分是圖面座標，SpiffWorkflow 不會讀）
